# StarBook Website

Marketing and landing page for StarBook platform.

## Tech Stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS

## Development

```bash
npm run dev
```

Opens at http://localhost:3000

## Build

```bash
npm run build
npm run start
```

## Features

- Hero section with CTA
- Feature showcase
- Responsive design
- Dark mode support
- SEO optimized
